# Facts the user must supply — wp-reply-affidavit

- Writ number, seat (Principal / Nagpur / Aurangabad / Kolhapur), parties
- Which respondent is filing; deponent name, designation, authorisation
- Impugned notice / order and the petitioner's case in one sentence
- Our record: service, hearing, inspection, prior orders, status of structure / action
- Which preliminary objections to keep (and facts for each)
- Documents for ANNEXURE-R-1… (with dates)
- Whether ad-interim relief needs vacating
