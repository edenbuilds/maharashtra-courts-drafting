# Stay / Interim Application

Separate petition. Own cause title, short facts, prayer, affidavit. Do not bury stay inside the main pleading.

Plead: prima facie case, balance of convenience, irreparable injury. Name the exact order / notice to be stayed and the operative date. Pack with the main writ or appeal.
