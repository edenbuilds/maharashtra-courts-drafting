# Criminal Writ Petition

Use for habeas corpus, challenge to preventive detention, quashing where the user expressly wants a writ rather than s.528 BNSS / s.482 CrPC, or a police-inaction mandamus.

Bhajan Lal categories belong in the grounds when quashing is sought. Do not invent extra categories. Produce the FIR / detention order as the first annexure.
