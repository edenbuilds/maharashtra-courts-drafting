# Long-form official templates — Maharashtra

Fill-in pleadings in the register used at the High Court of Judicature at Bombay and the working Maharashtra forums.

How to use:

1. Pick the forum-config (`forum-config/exemplars/`).
2. Copy the template below that matches the instrument.
3. Replace every `[BRACKET]` from the fact ledger. Delete unused optional blocks.
4. Do not invent a citation, fee or limitation article.
5. Opposite-side drafts (reply / written statement / rejoinder) are first-class instruments, not afterthoughts.
