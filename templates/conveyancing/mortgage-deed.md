# Mortgage Deed — Maharashtra

Identify the species. Registration and stamp follow the species.

```
DEED OF [SIMPLE / ENGLISH] MORTGAGE

THIS DEED is made at [Place] on [date]

BETWEEN

[Mortgagor] ("the Mortgagor")

AND

[Mortgagee — bank / individual] ("the Mortgagee")

WHEREAS the Mortgagee has agreed to lend Rs. [Amount] and the
Mortgagor has agreed to secure the loan on the property
described in the Schedule.

NOW THIS DEED WITNESSES:

1.   The Mortgagor conveys / transfers by way of [simple /
     English] mortgage the Schedule property to the Mortgagee
     as security for Rs. [__] with interest at [__]% per annum
     [compounded __].

2.   The loan shall be repaid as follows: [EMI / bullet].

3.   So long as default is not made, the Mortgagor shall
     [retain possession — simple mortgage] / [deliver
     possession — if English mortgage so provides].

4.   On default the Mortgagee shall be entitled to [the
     statutory and contractual remedies — including
     SARFAESI if the Mortgagee is a secured creditor].

5.   The Mortgagor declares that the property is free from
     encumbrance save [disclose].

SCHEDULE OF PROPERTY
```
