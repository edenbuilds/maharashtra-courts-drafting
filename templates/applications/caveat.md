# Caveat — Section 148-A of the Code of Civil Procedure

File in the High Court or the trial court that is likely to be moved ex parte. Serve the expected applicant.

---

```
IN THE HIGH COURT OF JUDICATURE AT BOMBAY.
[OR bench line / trial-court header]

CAVEAT APPLICATION NO.               OF 20__

[Caveator]                                           … Caveator

                ///VERSUS///

[Expected applicant]                                 … Caveatee


        CAVEAT UNDER SECTION 148-A OF THE
        CODE OF CIVIL PROCEDURE, 1908


THE CAVEATOR ABOVENAMED MOST RESPECTFULLY SHEWETH:

1.   The Caveator is [identity]. The Caveatee is expected to
     move this Hon'ble Court for [writ / appeal / stay /
     injunction] in respect of [order / property / file number].

2.   The Caveator is a person who will be affected by any
     ex-parte order in that proceeding.

3.   The Caveator undertakes to bear the costs of the Caveatee
     if this Caveat is found to have been lodged without due
     cause.

                             PRAYER

     a)    record this Caveat and issue notice to the Caveator
           before passing any interim / ad-interim order on any
           application that the Caveatee may file in respect of
           [subject];

     b)    pass such other order as may be deemed fit.

Place: [PLACE]
Date:  [__].[__].20__

                                              ([NAME], Advocate)
                                              Advocate for the Caveator

Address for service: [chambers / office address and email]

                    AFFIDAVIT IN SUPPORT

[Short first-person affidavit of the Caveator.]
```
