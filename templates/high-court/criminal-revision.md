# Criminal Revision — BNSS / CrPC ss.397, 401

Revision is not a second appeal. Plead perversity, jurisdictional error, or failure to consider material evidence. Meet the bar on interlocutory orders.

```
IN THE HIGH COURT OF JUDICATURE AT BOMBAY.
[OR bench line]

CRIMINAL APPELLATE JURISDICTION

CRIMINAL REVISION APPLICATION NO.    OF 20__

[Applicant]                                          } … Applicant

                ///VERSUS///

1.  The State of Maharashtra
2.  [Opposite private party]
                                                             } … Respondents

        CRIMINAL REVISION APPLICATION
        UNDER [SECTIONS 438 / 442 OF THE BNSS
        / SECTIONS 397 AND 401 OF THE CrPC]


1.   The Applicant is aggrieved by the order dated [__] passed
     by the learned [Sessions Judge / Magistrate], [Place], in
     [case number], [dismissing the discharge / refusing to
     recall a process / affirming conviction in a summons trial].
     ANNEXURE-A.

2.   [Short facts.]

                           G R O U N D S

A.   The order is without jurisdiction because [__].
B.   The order is perverse in that it ignores [document /
     binding section].
C.   The order is not interlocutory because it [finally decides
     the discharge / the process].

                             PRAYER

a)   quash and set aside the order dated [__];
b)   [discharge the Applicant / drop process / acquit];
c)   interim stay of the impugned order;
d)   any other order as may be deemed fit.
```
